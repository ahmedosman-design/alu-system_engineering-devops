\# Firewall



This project configures ufw (Uncomplicated Firewall) on web-01 to block all incoming traffic except SSH, HTTP, and HTTPS.



\## Tasks

\- 0-block\_all\_incoming\_traffic\_but: Configures ufw to allow only ports 22 (SSH), 80 (HTTP), and 443 (HTTPS), denying all other incoming traffic by default.
